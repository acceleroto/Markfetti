## Description (4000)
Markfetti is a fast, focused Markdown viewer for your Mac. Open a README, notes or documentation file and see it the way it's meant to look, with clean, familiar styling in light and dark mode.

EVERYTHING YOUR README USES
• Extended Markdown: tables, task lists, strikethrough, autolinks and footnotes
• Alerts: Note, Tip, Important, Warning and Caution callouts
• Syntax highlighting for about 80 languages, with one-click copy
• Emoji shortcodes, heading anchors and common HTML, including collapsible sections, keyboard keys and dark-mode images

MATH, DIAGRAMS, MAPS AND 3D
• Math: inline and display equations, typeset with KaTeX
• Mermaid: flowcharts, sequence diagrams, Gantt charts and more, drawn from plain text
• Maps: GeoJSON and TopoJSON blocks become interactive maps
• 3D models: STL blocks render as models you can rotate and zoom

BUILT FOR READING
• Live reload: edit the file in any editor and Markfetti updates as you save, keeping your place
• Outline sidebar to jump between headings
• Find, zoom, and a raw source view
• Links to other Markdown files open in Markfetti; web links open in your browser
• Print and export to PDF, always in a clean light theme
• Quick Look: press the space bar on a Markdown file in Finder to see it rendered

PRIVATE BY DESIGN
Markfetti renders everything on your Mac. It collects no data and has no accounts or tracking. Network access is only used for images and map tiles that a document links to.

## App Review notes
Markfetti is a read-only Markdown viewer. To try it, open any .md file (File ▸ Open, or drag a file onto the Dock icon). A sample that uses every feature is at https://github.com/acceleroto/Markfetti/blob/main/samples/kitchen-sink.md (download it together with the samples/images folder).

Sandbox note: when a document refers to images in its folder, the sandbox doesn't let the app read them until the user grants access. Markfetti then shows a banner, "Some images are in a folder Markfetti hasn't been given access to", with an "Allow Access…" button that opens a standard folder picker. The grant is remembered with a security-scoped bookmark. Network access (com.apple.security.network.client) is used only to load remote images and map tiles that a document references.

The app includes a Quick Look preview extension: select a .md file in Finder and press the space bar.

No sign-in or account is needed.
